Auto Scaling infrastructure with Terraform

A multi-AZ AWS setup built from Terraform modules for the VPC, security groups, load balancer and Auto Scaling group, plus a bastion host. State is stored remotely in S3. A Jenkins pipeline runs format check, validate and plan, waits for manual approval, then applies.

Zero Touch Kubernetes CI/CD

A Jenkins pipeline that builds frontend and backend images, tags them with the build number, pushes them to Docker Hub and deploys them to a K3s cluster with Helm. It checks the rollout and rolls back automatically if it fails. Pods run with readiness and liveness probes and resource limits.
